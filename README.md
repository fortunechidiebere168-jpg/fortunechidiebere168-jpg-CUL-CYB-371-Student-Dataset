# CUL-CYB 371 – Student Dataset

## Project description
This project contains a fictional dataset of 20 students. It was created with Python for the Data Mining and Data Warehousing assignment.

## Dataset fields
1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

## Files
- `main.py` – Python program containing the fictional student records and code to generate the CSV file.
- `student_dataset.csv` – The generated dataset in comma-separated values format.

## How to run
1. Install Python 3 if it is not already installed.
2. Open a terminal in this project folder.
3. Run: `python main.py`
4. The program creates `student_dataset.csv`.

## Note
All student records and scores in this project are fictional and are for academic demonstration only.
